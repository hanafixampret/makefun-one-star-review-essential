One deadpan one-star review, one sentence, under 160 characters. `main.ts` writes it to `<output>/entry.txt` so the AI judge can compare it head to head against the other entries.

The review: "One star. The pillow is cool for exactly four seconds, then warm for the rest of the night."

## Run it

```sh
node main.ts
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` when that variable is unset).
